Project Goal

This project is an analysis for exploring the correlation between Vienna's growing population and the expansion of its public transport infrastructure.

Data Sources

This visualization uses datasets from data.gv.at for graphs and the interactive map of Vienna.

Methodology

For the "Ticket Sales" dataset, linear interpolation was applied to missing yearly values to ensure a continuous data series.

Target Audience

This project is designed for all residents and visitors to help them understand transport accessibility and the history of the transport infrastructure.
